## Frozen questions

LC4V7D1 separates four public aggregate categories into explicit layers:

1. `speech_like_time`: does lossless normalization retain the exact spoken
   fragment and span while supplying a canonical time, and does extraction use
   that canonical value without replacing the source text?
2. `cross_turn_interval`: do additive lower and upper bounds compose across
   turns while correction turns still replace the prior complete relation?
3. `ambiguous_practitioner_alternatives`: does extraction require
   clarification for every implemented action and surface only the exact
   alternatives in source order, with policy preserving them?
4. `unknown_practitioner_schedule_explanation`: may extraction recognize an
   exact name while Option A policy refuses to describe an authoritative
   schedule until that name maps to a synthetic practitioner ID?

The fourth distinction is intentional. Context-free extraction can recognize
`Dr Rowan`; only policy owns roster resolution. An unknown practitioner must
produce clarification, no `find_slots`, no downstream completion outcome, no
deltas, and no simulated write.

`app/services/bernie/certification_decision_taxonomy.py` must implement this

1. one or more evidence-procedure failures -> `certification_invalid`;

3. valid evidence plus zero product-gate failures -> `certification_pass`.
