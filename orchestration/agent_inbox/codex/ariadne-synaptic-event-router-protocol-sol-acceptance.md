## Acceptance

The authorised repository-local, authored-synthetic, non-executing protocol
tranche satisfies its frozen plan. It proves deterministic scope leases,
event intersection, typed mailbox steering, replay suppression, fresh-read
grants, forward-only reconciliation/supersession and inspectable default-deny
dry-run manifests without attaching any runtime actuator.

The final architecture correctly extends the accepted Sandbox DAG rather than
creating an ambient second messaging system. Router outbound policy and node
inbound lease must bilaterally name the peer, control channel, notice kind and
frame. Every notice carries workflow/graph revision, immutable sender/recipient,
correlation, provenance and freshness. Sandbox-to-sandbox control remains
forbidden.
