## API Spine acceptance

The typed projection frame is non-authoritative client presentation state.
GraphQL/read models may provide current authorised context but remain
read-only. Touch or keyboard selection is staff input only. Proposal review is
not commitment. Every future appointment mutation continues through the
existing REST/OpenAPI confirmation family with backend identity, practice,
role, availability, conflict, freshness, idempotency, audit and receipt checks.

Committed events remain signals to perform current scoped reads. They carry no
display truth or command authority. The concept fixture path cannot write.

No runtime API, database schema, GraphQL mutation, appointment command,
production Diary component, event producer/consumer, background process or
deployment changed.
