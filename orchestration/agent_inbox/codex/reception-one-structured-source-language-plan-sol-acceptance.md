`accepted_for_bounded_implementation_and_conditional_exact_lane_rehearsal`

The redesign is a narrow, versioned correction to the observed transcription
failure. It replaces opaque arithmetic prior-output codes with fixed-shape
typed references while preserving the accepted goal and operator catalogue,
the independently screened audit-only note, the deterministic compiler,
semantic proofreader and proposal-only executor.

The design preserves the API Spine:

- no GraphQL mutation is added;
- no REST route or appointment command is changed;
- no database, event or product-write authority is introduced;
- the model cannot confirm or mutate an appointment; and
- backend identity, availability, conflicts, freshness, confirmation,
  idempotency, writes and audit remain authoritative.

Provider-schema conformance is correctly treated as an aid, not proof of
semantic validity. The local compiler must verify exact source-kind sentinels,
actual request-local bindings, backward-only step references, named output
existence and semantic type before the existing proofreader can admit release.
No semantic repair is permitted.

request-contract repair through the exact Gemini 2.5 Flash, Bernie project and
service account, keyless impersonated ADC and Australia-Southeast1 Vertex
hostname, under USD 1 and stopping after the first admitted result. A semantic
