# Superseded provider-free selector rehearsal

deterministic grounding. Independent pre-occupied review then found that the
proofreader itself did not compare wall-clock proof time to the two-minute
lease. The evidence is preserved but superseded by the descendant that checks
`generated_at <= proof_time < expires_at` on every proof, including correction
attempts.
