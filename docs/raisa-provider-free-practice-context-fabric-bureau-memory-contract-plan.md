# Provider-free Practice Context Fabric and Bureau Memory Bank contract plan

Date: 2026-08-06

Status: frozen bounded implementation plan

## Result sought

Freeze the first executable grammar for Raisa's Practice Context Fabric without
opening any product or data surface. The descendant must prove that one
non-authoritative `ContextNeedCandidate` can be bound to backend authority,
narrowed by deterministic policy, woven from authored-synthetic recent-work
items and released only after a same-packet deterministic proofreader admits
the exact frame-set digest.

The result label is
`raisa_provider_free_practice_context_fabric_bureau_memory_contract_pass`.

## Included

- Closed Draft 2020-12 JSON Schema definitions for `ContextNeedCandidate`,
  `ContextAuthorityBinding`, `ContextNeed`, `ContextScopeGrant`,
  `BureauMemorySelector`, `BureauMemoryItem`, `ContextFrame`,
  `ContextFrameSet`, `ContextSelectorTrace`, `ContextWeaveTrace` and
  `ContextProofreaderTrace`.
- Pure, caller-clocked in-memory scope intersection, temporal clipping,
  selection, canonical hashing, weaving and proofreading.
- One authored-synthetic admitted packet and deterministic hostile mutations.
- One documentation-only GraphQL `Query` extension which accepts only the
  candidate; authenticated backend context supplies authority.
- Provider-free evidence with exact artifact hashes and zero side effects.

## Excluded

No patient, clinical, product or historical-PHI data; raw audit; real practice
database; persistence; retention setting; provider or external retrieval;
product route, resolver or service import; command or write; deployment,
production, release, Pages, protected evidence or protected-ref movement.
`docs/branding/` and unrelated receipt/state files remain preserved and
excluded.

## Acceptance

1. Every object and nested object is closed; unknown types and authority-bearing
   candidate fields fail schema admission.
2. Backend policy can only preserve or narrow Bureau, purpose, source, frame,
   field, time and cardinality scope.
3. Memory selection excludes stale-window, superseded and non-matching items,
   orders canonically and never exposes raw audit or command material.
4. A memory frame is `recent_collective_work`, read-only and
   `command_authority: false`; it cannot establish current truth, identity,
   present authority or execution success.
5. Proofreading binds the exact need, grant, selector, weave and frame-set
   digests and fails closed on expiry, supersession or tampering.
6. GraphQL composition parses with the existing read graph and adds no
   `Mutation`, `Subscription`, standalone memory root or authority input.
7. Static inspection and evidence prove zero provider, network, database,
   subprocess, product/runtime, filesystem-write and command effects.

## Recovery

Schema, deterministic or static failure blocks evidence regeneration and
external review. Repair remains provider-free and inside this file set. Any
material semantic disagreement returns to Sol; no failing packet is released.
