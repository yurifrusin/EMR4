## Candidate outcome

Real headless Chromium loaded the ordinary loopback standalone Diary page and
both published application-session practitioner ES modules. The exact enabled
fixed reader rendered Avery Browser Synthetic and Morgan Browser Synthetic in
the visible booking modal. The pre-transition request ledger contained zero
GraphQL and zero legacy REST practitioner reads.

One held enabled read was then invalidated by disabling the trusted bootstrap
before an ordinary visible Refresh. The post-disable ledger recorded exactly
one GraphQL and zero REST practitioner reads; the legacy practitioner rendered,
the late stale row never rendered, and a final visible feature-off Refresh
recovered the same legacy directory. The total transition ledger remains
separate and records the two intentional feature-off GraphQL reads.

An independent enabled-reader rejection loaded the real modules but rendered no
grid children, left the grid container hidden, made no legacy practitioner
request and exposed only the fixed generic application-session failure marker.
With the bootstrap property absent, Chromium loaded no application-session
module and rendered the exact legacy GraphQL practitioner after one GraphQL and
zero REST practitioner requests.

All API fixtures were drawn from a closed path-and-method allowlist. No unknown
API path, wrong method, unexpected external host, provider host or console error
remained. The result is exactly `route_intercepted_browser` over
`authored_synthetic` values.

## Browser path and review corrections

The available in-app Browser was used first. It passed page identity,
non-blank standalone smoke rendering, console health and one visible Refresh
interaction. Its supported surface has no request routing or pre-document
initialization, so it could not establish the frozen route-intercepted
bootstrap. The repository Playwright harness was used as the explicitly
permitted fallback.

The worker's first rehydration packet returned `revision_required` for four
preflight reasons: `continuation_event_missing_or_unapproved`,
`adapter_probe_method_invalid:codex_subagent_spawn`,
`workspace_receipt_missing:native_diary_route_intercepted_browser_worker`, and
`context_observation_missing:orchestrator`. No task implementation or browser
action occurred before that receipt. The control correction changed the event
to `pre_worker_dispatch`, used the configured synthetic adapter observation,
bound the context observation to `orchestrator`, and removed the premature
active/assigned worker claim. The preserved second receipt then passed with all
five exact rehydration sources.

Root review also removed initially generated screenshots because deterministic
DOM/state, module-load and network-ledger assertions fully prove the frozen
behavior and Yuri had offered to avoid token-expensive/high-resolution image
work. Screenshots are intentionally excluded, the two untracked image files
were deleted, and no screenshot was staged or committed. This was a root review
scope correction, not an agent-error classification.
