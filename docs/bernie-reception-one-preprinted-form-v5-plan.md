existing PlanProgram v3 form when the one-use broker, rather than the model,

1. `operator_note`;
2. `goal_code`; and
3. `steps`.

The broker owns:

- attempt and ledger identifiers;

- provider/project/identity/region binding;

validates the assembled object against the unchanged PlanProgram v3 schema.

field. The deterministic compiler and proofreader remain unchanged.

3. the rendered Compass report validates;
4. JSON Schemas and policy manifests validate;
5. provider-blocked tests prove exact body parsing, broker field injection,
   complete-replacement correction and fail-closed rejection;

7. API Spine tests and relevant repository tests pass;
8. existing Bernie ADC, entitlement and exact provider controls pass without

An occupied result passes only if the model body, broker-assembled PlanProgram,
compiler, semantic proofreader, freshness/authority gates, operator-note gate

rejected note, credential, provider key or hidden reasoning may enter evidence.

was assembled with a broker-owned fixed field, and survived the deterministic
compiler/proofreader through the configured Sydney locational endpoint.

It cannot prove production suitability, general accuracy, training necessity,
Australian physical or sovereign processing, clinical safety, product-data
admission, write authority or deployment readiness.
