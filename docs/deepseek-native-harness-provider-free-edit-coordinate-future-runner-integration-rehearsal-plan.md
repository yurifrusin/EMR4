## Frozen typed mechanism

The derived runner exports two deterministic functions.

`preflightEditArguments(arguments)` returns exactly one closed decision:

- `defer_to_tool_schema` when the three relevant strings are not all present;
- `deny_blank_file_path`;
- `deny_empty_old_string`;
- `deny_equal_old_new`; or
- `admit_semantic_constraints`.

Each denial releases the already accepted shared result coordinate
`edit_error_untyped_argument_constraint`; admission and schema deferral release
no premature result coordinate. The detailed decision remains typed and local,
so no human-readable error text becomes a routing interface.

`classifyEditArgumentResult(observation)` accepts only the same four closed
fields as the accepted Python classifier and releases exactly one of:

- `edit_success_unique_match`;
- `edit_success_replace_all`;
- `edit_error_invalid_args`;
- `edit_error_untyped_argument_constraint`;
- `edit_error_fs_stale_version`;
- `edit_error_fs_edit_not_found`; or
- `edit_error_fs_ambiguous_edit`.

Unknown keys, values, combinations, codes, mutations or coordinates fail
closed. The runner terminal records only the pre-dispatch decision and final
coordinate alongside its existing typed lifecycle fields; it retains no raw
arguments, file content or error prose.
