# Ariadne S8H Runtime Hardening Closeout

Date: 2026-07-13
Status: implemented and published through `cb45eb1d`; live detached acceptance pending S9 planning

S8H repaired four recurring orchestration costs before the S9-S12 EMR4 tranche.

## Changes

- DeepSeek 4 Pro/high is now the routine Conductor. Fable, then Opus, are
  escalation resources for programme boundaries, architecture disputes,
  material product policy, or repeated sprint failure. A distinct Sol subagent
  remains the final fallback.
- A canonical artifact marker now constitutes worker completion. The PTY
  adapter no longer waits for DeepCode's unreliable TUI status line before
  starting controlled exit.
- Live PTY supervisors can launch detached. Outer shell or receipt-wait timeouts
  no longer own or terminate worker lifecycle; receipt polling is re-entrant.
- Every DeepCode prompt receives exact shared integration-worktree Python and
  Node paths. Workers must try those tools before claiming they are unavailable.

## Security

Detached execution does not expand worker authority. Permission prompts still
fail closed. Artifacts, receipts, cleanup, Git ancestry, independent review, and
Sol integration remain mandatory. Network, deletion, out-of-worktree access,
worker push, and integration authority remain denied.
