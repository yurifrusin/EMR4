## Lane C: controlled recovery intelligence

### C1. System-anatomy and observation contract

Define a version-bound, read-only technical graph containing service versions,
deployment manifest references, schema head, dependency state, health and
capacity signals, sanitized error classes, backup verification, configuration

data and generic database introspection. Deterministic collectors label every
observation with source, time, freshness and confidence class.

### C2. Diagnostic candidate and proofreader

Define strict model output schemas for hypotheses, evidence links, missing
evidence, likely impact, urgency, candidate runbook and user explanation.
Require an approved provider model for the diagnostic dialogue. The proofreader
must reject unsupported causes, absent evidence, stale anatomy versions,
unknown runbooks and any free-form executable instruction.

C2 is read-only and has no actuator.

### C3. Recovery-plan and authority policy

Define deterministic risk tiers and authority requirements. At minimum:

- observe/explain only;
- reversible scoped service recovery;
- human-approved rollback or failover;
- dual-reviewed database, security or data-supply operation; and
- forbidden autonomous actions.

Each plan names exact preconditions, environment, target, expected effect,
maximum blast radius, rollback, expiry, idempotency, audit and postconditions.

### C4. Allowlisted actuator rehearsal

Only after a material actuator decision, build a provider-free authored-
synthetic simulator that accepts one-use typed execution evidence for exact
runbooks. It must reject shell/SQL text from the model, unknown parameters,
scope expansion, stale plans, replay and partial verification.

No production deployment or real database is part of C4.

### C5. Live development recovery

Any live development action requires separate exact target and authority. Begin
with a disposable, non-PHI, reversible fault in an isolated environment. The
provider model remains mandatory for diagnosis and explanation; deterministic
policy and human approval remain mandatory for execution where the risk tier
requires them.
