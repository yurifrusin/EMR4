## Objective

controller and the frozen serial live rehearsal. The descendant adds one
C5-only Vertex diagnosis cell, one source-bound pre-execution receipt builder,
one serial orchestration entry point and sanitized terminal evidence. It does
not change the accepted target, fault, runbooks, provider, model, identity,
region, data, call, cost, authority, rollback, cleanup or claim boundary.

   no credential and transmit no C5 frame.

## Deterministic and independent gates

Before a C5 target, socket, port, task directory, ADC read or provider call:

- provider request, response extraction, correction eligibility, cost ledger,
  source/pre-execution binding, no-retention evidence and terminal cleanup pass
  provider-free tests;
- the existing C5/C4/C3/Gate-zero/API-Spine suites, Ruff, compilation, Bandit,
  JSON/YAML validation and `git diff --check` pass;
- the candidate is committed to the existing non-protected task branch; and
- a fresh Gemini 3.6 Flash/high project reviews that exact clean HEAD, returns
  one terminal `pass` and changes no file.

Only then may the distinct pre-execution receipt be generated. The receipt is
an admission control, not execution authority by itself.

## Permanent exclusions and stop conditions

No patient, clinical, historical-Diary, participant, product-derived,
protected or production data; product API/database/runtime; ordinary service;
provider tool or retrieval; raw prompt, response, thought or credential
retention; credential/IAM mutation; container, VM or cloud target; generic
shell, SQL or command runner; deployment; production; release; Pages;
protected evidence; protected-ref movement; or Context Fabric implementation
is opened.

Stop before live action on any source, review, pre-execution, cloud/ADC or
cleanup failure. A human pause is required only for an indispensable credential
restoration or console action, exhausted bounded recovery, conflicting evidence
that changes acceptance, or a change outside the frozen parent envelope.
