## Corrected operating rule

was too brittle. The first pragmatic assignment never reached DeepSeek because
the stock runner advertised seven tools while the broker admitted three. The
broker behaved correctly; the mismatch was mechanical and attributable.

runner. One small reusable task-coupled runner/coordinator adaptation and one
focused deterministic test may be built inside the first real development

to make the stock runner pass.

## Lean clockwork coupling

The clockwork now reads the Harness at three boundaries only: `prepared`,
`terminal` and `accepted_or_recovered`. It does not tick for each model request,
tool call, edit error or reread. A small typed vocabulary records provider,
candidate, coarse failure stage and final disposition; detailed sanitized
diagnostics remain ordinary evidence rather than new canonical states.

This preserves fail-closed governance while removing the main source of
ceremonial friction: attempting to model every Harness subcoordinate as a
separate bureaucratic event.
