# Reception One Receptionist-first v6.1 Threat-model Delta

## New surfaces

v6.1 teaches the model that request-local bindings are grounded facts and adds
a one-way recognized-intent proofreader assertion.

## Threats and controls

- **A stamped binding is mistaken for permission.** Bindings supply data only.
  The effect ceiling remains proposal-only and all writes, confirmation and
  delivery remain closed.
- **The deterministic adapter silently replaces the model.** It asserts a goal
  only for supported explicit actions it already recognizes. Unknown novel
  actions continue to the typed compiler and proofreader.
- **A noun fragment becomes an appointment-create request.** A bounded
  grounded-detail-fragment check rejects a create form where no action was
  expressed.
- **The proofreader rewrites a failed form.** It emits only a coded correction
  ticket. The model must submit one complete replacement; no deterministic
  semantic repair or proofreader-selected value is permitted.
- **The targeted rerun is presented as independent evidence.** Every artifact
  labels it development-only and binds it to the exact fifteen closed v6
  misses.
- **Natural speech becomes executable.** The receptionist response remains a
  separate bounded audit channel and is never parsed into typed fields.
- **Thinking content leaks.** `includeThoughts` remains false. Only the
  provider-supplied thinking-token count may be retained.

All inherited Sydney endpoint, keyless ADC, one-use broker, isolation,
no-fallback, no-tool, no-product, cost, cleanup and external-audit controls
remain unchanged.
