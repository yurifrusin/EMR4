# Threat-model delta: unmounted Rayleen fresh-generation rehearsal

Date: 2026-08-06

Status: frozen bounded provider-free design delta

## Trust boundaries and assets

The accepted old packet, requirement and inert instruction are authoritative
only after deterministic reconstruction. Newly authored synthetic request,
authority trace, source inputs, adapter results, frame set and admission packet
remain untrusted until complete same-packet reconstruction and proofreading.

Protected assets are practice/session/grant isolation, complete affected-
dependency refresh, source/event separation, request-scoped aliases, immutable
retired context, distinct generation identity, deterministic supersession and
the absence of live read, provider or command authority.

## Threats and controls

| Threat | Control |
|---|---|
| Inert instruction is interpreted as permission to read | Treat ordered steps only as sealed obligations; no callback, credential, route or source reader exists and every execution flag remains false. |
| Event metadata is used as replacement context | New Diary and waiting values are independently authored inputs; the signal is referenced only by predecessor requirement digest. |
| Only the convenient waiting source is refreshed | Exact equality between requirement dependency ids and refreshed dependency ids; missing Diary refresh blocks. |
| Fresh authority silently widens scope | Recompute need/grant and compare every identity, tenant, role, Bureau, purpose, source, field, location, window, limit, freshness and authority ceiling. |
| Unaffected source is carried past expiry or after impact | Carry-forward requires non-membership in required dependencies plus exact digest, grant, coherence and freshness checks at the new instant. |
| New waiting result detaches from A4 source | Accepted adapter extractor reruns from authoritative new frame, binding, grant and alias manifest; full provenance is reconstructed again. |
| New frame set collides with retired generation | Distinct need id, frame-set id, request revision, refreshed source revisions and exact digest inequality are mandatory. |
| Old manifest, lease or checkpoint is reused | Derive a new manifest/lease only from the released new frame set; no predecessor checkpoint field is eligible. |
| Slow old result overwrites current generation | Accepted stale assessor plus current-revision admission gate; both completion orders must converge on the newer frame set. |
| Self-consistent reseal bypasses admission | Final proofreader reconstructs every input and derived object and releases only its trusted deep copy. |
| New generation restores or patches old frames | Canonical before/after old-frame bytes, monotonic retired state and explicit different new frame-set identity. |
| Rehearsal is mislabeled live | Strict authored-synthetic/unmounted evidence label and static zero-surface checks for database, watcher, source-read, route and runtime imports. |
| Command or provider authority enters through composition | Recursively closed schemas, fixed false ceilings, no `app/**`, provider or command imports, and inherited API Spine tests. |

## Residual risks deliberately deferred

Real PostgreSQL/outbox/feed delivery, transaction ordering, persistent
checkpoints, restart recovery, RLS/ABAC, operational deduplication, genuine
source authorization, patient privacy, load, retention, provider context use
and command safety require separately frozen descendants.

## Forbidden openings

No patient, clinical, financial, product-derived, historical-PHI or protected
data; no raw audit; no live database/session/feed/watcher/listener/source
reader; no persistence, broker, background worker or retention scheduler; no
provider or external retrieval; no GraphQL/REST route, resolver, mutation or
subscription; no command/write; no product runtime; no deployment, production,
release, Pages, protected evidence or protected-ref movement. Preserve and
exclude `docs/branding/` and unrelated untracked artifacts.
