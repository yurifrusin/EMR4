# Threat-model Delta — Reception One v5 Broad Language Cohort

Status: closed at the occupied credential gate; controls passed
Recorded: 2026-07-30

## New exposure

The cohort increases the number and linguistic variety of authored-synthetic
requests sent through the already accepted one-use Sydney Vertex lane. It does
not add a new provider, credential, product context, data source or effect.

## Threats and controls

| Threat | Control |
|---|---|
| A paraphrase is treated as write authority | Typed effect ceiling remains `proposal_only`; no route or database is available |
| Surface detail tempts an unsupported action inference | Predeclared deterministic oracle and proofreader require clarification; no proposal may escape |
| A correction leaks state between cases | Distinct case-bound attempts, ledgers and parent chains; cross-case pairing fails closed |
| Repeated testing becomes prompt tuning | Prompt, schema and catalogue hashes are frozen; outcomes are analysed only after the cohort |
| A failed case triggers unbounded calls | One primary plus one eligible complete replacement; forty-eight-call absolute ceiling |
| Raw natural-language or provider output enters audit | Evidence retains hashes, typed admitted fields and bounded findings only |
| API-key credentials leak from the host | Keys are neither inspected nor copied; child environments omit provider-key variables |
| The occupied cell receives ADC/OAuth material | Only the one-use host broker may call `google.auth.default()` |
| Provider or region fallback weakens locality | Exact Sydney hostname, model, project, identity and no-fallback checks bind every call |
| Accepted evidence is overstated | Closeout separates configured/observed locational routing from physical or sovereign processing |

## Closed surfaces

Protected holdouts, historical Diary material, product/database reads,
patient/clinical data, GraphQL mutations, REST command invocation, appointment
confirmation or write, product delivery, Word, voice, production, deployment
and release remain closed.
