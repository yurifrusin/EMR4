# Reception One Structured Source Language Threat-Model Delta

## Added boundary

This descendant replaces arithmetic prior-output codes with fixed-shape
`source_ref` objects. The provider sees a closed source-kind enum, bounded
integer coordinates and a frozen output-property enum. The trusted compiler
converts only schema-admitted references into the accepted PlanDraft; it
remains incapable of interpreting prose or inventing a dependency.

The existing independently screened audit-only `operator_note` boundary is
unchanged.

## Principal threats and controls

| Threat | Control |
|---|---|
| A clearer form becomes broader authority | The new representation changes only model-to-proofreader transcription. The accepted operator catalogue, proposal-only effect ceiling, semantic proofreader, human gate and backend command ownership remain unchanged. |
| `kind` and coordinate fields contradict one another | Every field is required. The compiler enforces exact sentinel combinations for `binding`, `prior_output` and `omit`; inconsistent objects fail before semantic proofreading. |
| A prior step or output property is fabricated | References must target an earlier existing step and a frozen output name actually exposed by that step's selected operator. |
| A valid property has the wrong semantic type | The compiler checks the exact output semantic type against the receiving operator's exact input slot. |
| A binding code names no grounded request value | Binding codes index only the request-local table and are range-checked against its actual length. |
| A free-form identifier becomes a covert channel | Operator, goal and binding selectors remain bounded integers; source kinds and output properties are closed provider enums; local schemas reject additional fields. |
| The provider schema is mistaken for complete verification | Cross-field and graph semantics remain the deterministic compiler and proofreader's responsibility. Provider conformance alone never admits release. |
| The note changes or repairs the typed program | The note remains independently gated, audit-only, never parsed, executed or product-delivered, and cannot supply missing evidence. |
| A rejected model draft is silently corrected | No semantic repair is allowed. A source reference selected by the model is either admitted as written or the complete program fails closed. |
| A second call becomes an outcome retry | The only eligible retry is an exact deterministic request-contract repair after audit, focused regression and complete gate rerun. Semantic output failure ends the sequence. |
| Product command authority leaks through the adapter | There is no API route, database access, confirmation call or write actuator in this descendant. Only proofreader-admitted authored-synthetic in-memory proposals may be released. |
| Provider or credential fallback weakens controls | Exact Gemini 2.5 Flash, Bernie project and service account, keyless impersonated ADC, Sydney endpoint and no-fallback checks are frozen and audited. |
| Remote geography is overstated | Evidence is limited to Google's published regional support, configured endpoint and observed hostname; no Australian physical or sovereign-processing claim is permitted. |

## Unchanged stops

Real, product-derived, patient, health, clinical, protected and historical
data; GraphQL mutations; REST writes; appointment confirmation; model-to-
database action; provider tools; explicit cache creation; global or cross-
region inference; API keys; Word; voice; production; deployment and release
remain closed.
