## Threats and controls

### A fresh measurement becomes another retry loop

Threat: the consumed v1/v2 attempts are resumed, compared adaptively or rerun
after an inconvenient v3 result.

Control: only the literal absent v3 root is admissible. Phase A and Phase B each
have a counter of one. The content terminal is written before Word launch and
every result is final without retry. Prior attempt roots are never inputs.

### Parser or thresholds are tuned after private access

Threat: observed historical behavior changes token grammar, separator,
denials, mapping ratio, interval or candidate meaning.

Control: source digests and the complete 219-or-later provider-free suite bind
the parser, extractor and decision rules before Phase A. Digest drift or any
post-bind rule change blocks Phase B or acceptance.

### Leading syntax admits private contact or date values

Threat: a clock-like prefix in a phone, email, date or identifier creates a
mapped payload.

Control: anchored complete-time syntax, allowlisted separators, non-empty
payload, date/phone/email denial and hostile controls are frozen. The parser
never searches for an embedded token and never emits its input.

### Time is invented for neighbouring content

Threat: an admitted time is carried into another segment, row or cell.

Control: the parser has no retained clock state. Direct time applies only to
the successful same-segment payload. Every other segment independently parses
or uses the unchanged bounded coordinate fallback.

### Private syntax survives stable tokenization

Threat: source clock labels persist in normalized occupancy or HMAC material.

Control: the accepted byte-equivalence proof requires token and separator
removal before normalization and HMAC construction. Ephemeral keys and private
projection are removed for every terminal result.

### Longer Word work strands or kills the wrong process

Threat: the 1,800-second run leaves an owned Word child or stops the user's
pre-existing Word session.

Control: cleanup requires exact PID, `WINWORD` class and UTC start-time ticks.
Missing or mismatched identity blocks; process-name fallback is forbidden. The
pre-existing process set is captured and must be preserved.

### Progress or retained aggregate becomes a side channel

Threat: per-document timing, source values or private layout escape through
progress, errors or retained output.

Control: progress is count-only and coarsely bucketed. Strict schemas forbid
identity, path, exact timestamp, text, time, coordinate, distance, key and
mapping fields. Public retained readings are generic aggregates only; all
private sidecars are deleted and absence-checked.

### A positive run silently opens reuse

Threat: useful scheduling motion is immediately promoted to a development
fixture, benchmark, corpus, memory or product input.

Control: the first-use gate remains default-deny. The strongest result is one
ignored local research reading. A later gate must evaluate one specific
minimized derivative before its first reusable use.

## Residual risk

The parser may find zero useful tokens, or mapped payloads may represent breaks,
roster notes or other operations rather than appointments. Structural
uniqueness can still make a minimized derivative sensitive even when obvious
identifiers are absent. A contained `revision_required` result is therefore a
valid terminal, and a positive aggregate is not an anonymity or product-
suitability claim.
