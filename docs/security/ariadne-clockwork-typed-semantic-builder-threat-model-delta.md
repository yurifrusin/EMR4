# Governance clockwork typed semantic builder and command registry — threat-model delta

Date: 2026-08-23

Timestamp: 2026-08-23T17:17:00.4614783+10:00 (Australia/Brisbane)

Status: `frozen`

## Scope

This delta covers one provider-free semantic compiler, prospective-document
header materialiser and closed verification profile inside the existing
governance tick. It adds no Harness, provider, product, database, credential,
network, deployment, Pages or protected-ref surface.

## Threats and controls

| Threat | Control |
|---|---|
| A compact request silently weakens a legacy invariant | Expand to the existing admitted legacy intent, then run the unchanged legacy validator and projection path. |
| The builder becomes another form rather than removing work | Freeze a maximum of 100 caller scalar leaves against the measured 151-leaf no-incident baseline and forbid a second durable intent document. |
| A selector admits arbitrary labels, executables or tests | Admit exactly one semantic profile, Baton selector and verification selector; every expansion is repository-owned. |
| Repository paths escape or touch branding | Derive standard safe relative paths, validate every additional path, and reject `docs/branding/`, absolute, traversal and backslash forms. |
| Header preparation overwrites meaningful content | Insert only when both headers are absent, require an H1, reject partial/conflicting headers as a complete set, and prepare all bytes before any write. |
| A mid-write error leaves a partial header update | Use same-directory atomic replacements and restore every prior byte before returning failure. |
| A derived timestamp varies between invocations | Require one explicit ISO Brisbane `recorded_at`; derive Date and Timestamp deterministically and prove idempotence. |
| Verification commands permit shell injection or broad discovery | Execute fixed argument arrays with no shell, exact implementation paths and exact whole-file test paths only. |
| A failing command still moves the pointer | Run semantic verification before generation preparation and canonical writes; return typed rejection with zero publication and lease movement. |
| Verification mutates tracked source | Compare machine Git status before and after the profile and reject any tracked drift before preparation. |
| Check and publish duplicate expensive verification | Semantic check validates only; semantic publish runs the registry exactly once. |
| Legacy closeouts regress | Preserve v1/v2 validation and byte-semantic fixtures unchanged. |
| A new helper becomes a second governance system | Keep implementation in the existing tick/core/CLI files, the same canonical writer, and no new gate, ledger, approval or required closeout document. |

## Claim boundary

Passing evidence will show bounded typed compilation, header materialisation
and closed provider-free command execution for one governance-tooling profile.
It will not author semantic narrative, qualify arbitrary commands, open worker
transport, change product behavior, access protected evidence, or authorise
production, deployment, Pages or protected-ref movement.
