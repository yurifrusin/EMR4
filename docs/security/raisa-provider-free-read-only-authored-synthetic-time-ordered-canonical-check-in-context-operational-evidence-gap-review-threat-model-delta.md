# Threat-model delta: time-ordered check-in operational-evidence gap review

Date: 2026-08-24

Status: `frozen_read_only_delta`

## Changed surface

No product or runtime surface changes. This tranche adds only a deterministic
read-only evidence join over five exact tracked artifacts.

## Threats and controls

| Threat | Control |
|---|---|
| In-memory pairwise evidence is misrepresented as a physical route or database proof | Preserve its exact in-memory-only claim ceiling and classify physical backing separately. |
| A new combination of already-proved properties is treated as a new operational gap | Require a missing physical property, not merely a novel cross-axis pairing, before recommending a rehearsal. |
| Stale acceptance evidence silently reopens repository work | Bind the latest blocker-priority evidence and retain zero repository prerequisites remaining. |
| An abbreviated or substituted source weakens traceability | Require full 40-character ancestral Git objects plus canonical-LF SHA-256 for exactly five allowlisted sources. |
| Synthetic evidence is promoted into a live environment fact | Preserve six absent external facts, zero inferred facts and the existing human-decision boundary. |
| A read-only reviewer gains execution capability | Forbid app, route, database, Docker, SQL, network, provider, Harness and historical-data imports or actions. |
| A false success crosses the command boundary after an unknown response | Retain authoritative readback as mandatory and classify uncertain completion as non-success. |
| Evidence review changes API semantics | Preserve the confirmed, practice-scoped, idempotent and audited REST command; GraphQL remains read-only and events non-actuating. |

## Residual risk

The review can classify only tracked accepted evidence. It cannot establish a
live environment, current secret custody, rotation, break-glass posture or
independent operational freshness. Those remain external facts and human-owned
decisions, not defects that authored-synthetic rehearsal can close.

## Closed authority

Ordinary activation, product/API/client/configuration changes, product or
protected data, external systems, production, deployment, release, Pages and
protected-ref movement remain closed. A future lasting action still requires
the existing explicit human decision and final confirmation boundary.
