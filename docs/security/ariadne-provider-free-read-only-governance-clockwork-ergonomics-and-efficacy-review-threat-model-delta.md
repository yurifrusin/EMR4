# Clockwork ergonomics and efficacy review — threat-model delta

Date: 2026-08-23

Timestamp: 2026-08-23T15:51:11.6463935+10:00 (Australia/Brisbane)

Status: `frozen`

## Scope

This delta covers a provider-free read-only review of existing governance and
native-Harness workflow evidence. It adds no product, runtime, provider or
actuator surface.

## Threats and controls

| Threat | Control |
|---|---|
| Ergonomic simplification weakens a fail-closed gate | Every eligible proposal must retain the single writer, full-Git binding, closed vocabularies, protected-boundary floor, prospective validation and byte-exact rollback. |
| Another helper merely adds bureaucracy | A proposal is ineligible unless it removes at least one existing manual decision, duplicate field or rerun sequence and adds no net required operator field, approval, gate or document. |
| Unequal Claude/native evidence is turned into a model ranking | Retain the accepted prohibition on comparative rate claims; report only attributable origins and bounded outcomes. |
| Historical incident counts are mistaken for independent failures | Use the four frozen efficacy readings for disclosed lapse totals and the register only for classification/provenance; do not infer independence. |
| Postpublication validation discovers errors one at a time | Prefer a prospective complete-error-set validator over additional postpublication checks; no implementation occurs here. |
| Self-referential transaction counters force endless republishing | Treat attempts, leases, generations, rollbacks and final source bindings as machine-derived transaction outputs. |
| Typed selectors conceal inherited obligations | Require any future selector to preview its closed vocabulary and derived contract consequences before preparation. |
| A workflow review opens Harness or check-in operational authority | The active latch forbids provider, Harness, product, external fact, ordinary enablement and lasting-action surfaces. |
| Stale generic worker-allocation prose conflicts with the live operation-specific Baton | Record the inconsistency as a review finding; do not silently select either transport or mutate authority in this tranche. |
| Protected or user-owned files are swept into the review | Read only named non-protected paths; stage explicit paths only and preserve `docs/branding/` plus every unrelated untracked file. |

## Residual risk

The review can identify a high-yield simplification but cannot prove its effect
until a separately frozen implementation and matched future closeout sample.
That later tranche must demonstrate reduced operator surface without reducing
rejection coverage or rollback recoverability.
