# Reception One shared typed language — proofreader-feedback repair

## Trigger

Occupied lifecycle 002 made the descendant's first actual provider call.
Vertex returned HTTP 200 and the operator note passed, but the PlanProgram
referenced an output index not present on its selected earlier operator. The
deterministic proofreader aborted before release.

## Repair

Model input v3 preserves the same PlanProgram v2 response and adds:

- concrete zero-based prior-output code examples;
- the explicit rule that the selected earlier operator must expose the
  referenced output index;
- an optional closed proofreader-feedback packet containing only a version
  code, prior program hash, replacement flag, allowlisted violation code and
  closed path code; and
- audit retention of the schema-admitted integer-only typed form, with the
  independently gated operator note excluded.

The feedback asks for a complete replacement program. It contains no raw or
rejected draft, prompt, provider response, person name, identifier, credential,
hidden reasoning or product data. The deterministic proofreader is unchanged.

## Frozen boundaries

The repair does not alter the provider, model family, project, impersonated
service account, keyless ADC mechanism, Sydney locational endpoint, authored-
synthetic data class, isolated cell and broker topology, proposal-only effect
ceiling, proofreader release contract, no-fallback posture, USD 1 ceiling or
absolute two-provider-call ceiling. Confirmation, appointment writes, product
data, Word, voice, production, deployment and release remain closed.

Lifecycle 002 and its ledger remain immutable and consumed. A distinct
lifecycle may be opened only after the complete repository, provider-blocked,
real-isolation, Continuity, Compass, rendered-report and exact read-only
ADC/control gates pass again.
