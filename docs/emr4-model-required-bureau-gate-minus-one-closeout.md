## Outcome

Gate -1 passes as a research-backed, architecture-only adversarial review. It
assumes that direct or indirect prompt injection, a hostile provider response,
or compromise of the cognitive wrapper can produce deliberately malicious but
schema-valid output. It therefore does not rely on prompting, delimiters,
detectors, model refusal, human review or a container alone as an authority
boundary.

The accepted Gate-zero inputs are:

1. `bureau-labeled-capability-envelope`: trusted deterministic wrappers assign
   provenance, integrity, reader/confidentiality, freshness, scope and
   authority-ceiling labels; deterministic joins preserve them through every
   transformation; trusted-action rules cover action choice and every
   security-relevant argument; permitted-flow rules cover every response and
   egress sink. The model cannot assign, raise, endorse or declassify a label,
   grant a capability or create authority.
2. `one-shot-brokered-cell`: every Bureau attempt uses a fresh, broker-mediated
   cell with one typed input and one hostile candidate-byte output, immutable
   broker-owned provider transport, canonical hostile-byte parsing, bounded
   resources, deterministic kill/teardown and residue evidence. The cell has
   no ambient shell, code, tool, path, URL, callback, filesystem, socket,
   metadata, credential, database, network or actuator bridge.

Provider-model participation remains mandatory for the intelligent dialogue,
but it remains an untrusted candidate generator. GraphQL/context stays
read-only; command-shaped work stays on single-purpose REST/OpenAPI paths with
backend reauthorization, idempotency, audit and deterministic readback.
