## Outcome

The provider-free Reception One Bureau baseline passes with authored-synthetic
evidence.

Reception One now opens as a compact, modeless detail sheet over the still
visible ordinary Diary. Its composition follows Yuri's selected visual
reference: a calm navy title bar, white editorial appointment surface,
left-column dates, vertically assembled appointment detail, restrained status
language, a separated proposal row, and a low natural-language input strip
ending in a warm terracotta action. A
keyboard-operable title-bar control expands the same projection horizontally
into the larger Bureau console and collapses it again without changing the
request, Diary date, projection, route or authority state.

another day, the Diary moves and verifies that date before Reception One
settles the new projection. `Return to Diary`, ordinary close and `Escape`
converge on the same reversible action and restore focus to `Project view`.

## Provider-blocked typed lane

The repository-only lane prepares one future model contribution without
running a provider:

1. an authored-synthetic receptionist utterance enters an exact input frame;
2. an untrusted typed intent draft names only projection fields;
3. the deterministic proofreader checks schema, grounding, freshness,
   authority and context revision;
4. only admitted fields form a date-first typesetter instruction.

The positive `Show Dr Shera tomorrow` case is admitted with no repair. Unknown
authority fields, an ungrounded practitioner, a write-shaped operation, a
semantic date defect and stale context all reject. Mechanical normalization is
limited to whitespace, enum casing and deterministic ordering.

The frozen policy records:

- `execution_enabled: false`;
- `provider_call_count: 0`;
- `credentials_requested: false`;
- `network_requested: false`;
- `raw_prompt_persisted: false`;
- `raw_response_persisted: false`; and
- `product_delivery_enabled: false`.

Google Vertex AI, `gemini-2.5-flash`, the Bernie project and identity, Sydney
region and keyless impersonated ADC appear only as reference coordinates for a
possible later tranche. They were not contacted or inspected.

## What this proves

This proves that the compact projection, date-first Diary choreography,
reversible expanded Bureau modality, inherited read/proposal behavior and
provider-blocked typed contract operate coherently with authored-synthetic
fixtures.

It does not prove model interpretation quality, a live agent, provider
residency, production behavior, representative receptionist usability,
appointment mutation, clinical safety, voice interaction or release
readiness.
