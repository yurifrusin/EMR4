## Source-bound edit taxonomy

The rc.7 tool stack has three relevant boundaries:

1. `defineTool` validates the declared JSON argument schema and emits the stable
   Harness code `INVALID_ARGS`;
2. `parseEditArgs` enforces non-blank `file_path`, non-empty `old_string` and
   unequal old/new strings with plain `Error` values that carry no structured
   Harness code; and
3. `LocalFileSystem.editText` emits stable `FsError` codes for missing/stale
   targets, absent matches and ambiguous matches.

Successful results are proved through exact pre/post content hashes and
changed-path containment. Failed results must leave the fixture target
byte-identical.

Unknown codes, missing expected codes, a success with the wrong mutation, a
failure with any mutation, duplicate keys or extra fields fail closed.
