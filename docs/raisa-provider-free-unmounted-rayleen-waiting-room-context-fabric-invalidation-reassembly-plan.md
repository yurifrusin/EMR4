## Objective

Prove the first exact seam between the accepted Rayleen A4 waiting-room source
adapter and the accepted patient-free Context Fabric temporal control plane.
The seam must rebuild the authored-synthetic parent Current weave with the
adapter-produced waiting-room source, derive a temporal dependency manifest
from that exact immutable frame set, classify one typed payload-free relevant
signal, retire the old frame set and release one inert requirement for a wholly
fresh authorised adapter/assembler/proofreader cycle.

## API Spine classification

This is a provider-free, unmounted read-context lifecycle protocol. It adds no
GraphQL field, resolver, mutation or subscription; no REST/OpenAPI command; no
event producer, listener or transport; and no YAML authority. A committed-event
shaped signal is only a reason to withdraw stale context. It is never current
truth, a fresh read, a command or authority to perform one.

## Deterministic lifecycle

1. Build the accepted parent Current packet.
2. Build the authored-synthetic A4 frame and alias manifest through accepted
   public functions.
3. Run the pure source adapter, then call the sole extractor with the original
   authoritative frame, binding, grant and alias manifest so the result is
   independently recomputed before release.
4. Replace only the waiting-room source envelope in a deep-copied parent source
   list; rerun the unchanged Current assembler and same-packet proofreader.
5. Require `RELEASE` and bind the adapter result digest, extracted source digest,
   waiting frame digest, source-trace digest and rebuilt frame-set digest.
6. Derive the dependency manifest and watch lease from that exact rebuilt
   parent. Supplied or resealed substitutes fail equality checks.
7. Build one closed signal through the accepted temporal constructor. It has no
   payload, patient identity, free text, before/after state or replacement data.
8. Classify the signal through the accepted pure temporal processor. The parent
   frame-set bytes must remain identical, state must become
   `REASSEMBLY_REQUIRED`, and exactly one inert requirement must be emitted.
9. Derive the inert instruction from the authoritative requirement and bound
   adapter/source chain. It may name only:
   `fresh_authority_check`, `fresh_waiting_room_source_read`,
   `rerun_waiting_room_source_adapter`, `assemble_new_current_weave`, and
   `same_packet_proofread`.
10. The instruction fixes `execution_enabled`, `source_read_executed`,
    `returns_data`, `command_authority` and `provider_authority` to false. It is
    not executable work or a read capability.
11. Prove an earlier asynchronous request revision is rejected. No new frame set
    is created or admitted in this tranche.
12. The proofreader reconstructs the complete expected packet from the original
    authoritative inputs and signal coordinates, verifies canonical equality,
    exact expiry/authority ceilings and old-frame immutability, then releases or
    blocks atomically.
