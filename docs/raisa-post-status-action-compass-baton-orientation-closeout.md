## Outcome

The selected-appointment status action is a genuine architectural milestone:
the conventional grid and Reception One now have truth parity for one complete
command family. They express intention differently but converge on the same
kernel-owned proposal, confirmation, current-truth check, commit, audit and
receipt, then rebuild their visible state from the same Diary truth.

This is not yet feature parity. The conventional grid exposes more command
families, and their mere existence does not authorise a Reception One action.
The milestone instead establishes a projection-neutral test of correctness:
renderers may differ; authoritative meaning may not.
