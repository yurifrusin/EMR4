safe to rehearse locally, but it does not yet establish that Gemini can fill
or correct the live form. The live sequence tested request admission and
fail-closed parsing, not proofreader dialogue.

author the protocol version—for example, inject it deterministically after
parsing or represent it with a provider-supported closed string mapped locally.
That candidate is not tested here.
