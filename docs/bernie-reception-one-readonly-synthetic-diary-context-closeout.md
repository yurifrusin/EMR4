## What this proves

This proves the architectural seam: trusted deterministic database reads can
construct a minimal typed context for an isolated LLM, while the model remains
unable to read the database and the deterministic proofreader retains release
control.

It does not yet prove operational wall-clock freshness because this rehearsal
uses the frozen authored-synthetic proofreader clock. It does not prove safety
for real or product-derived information, production fitness, autonomous
booking authority, exhaustive language coverage, or Australian physical or
sovereign processing.
