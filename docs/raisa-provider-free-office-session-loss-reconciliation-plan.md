# Provider-free Office session-loss reconciliation plan

Date: 2026-08-03

Status: authorised second lifecycle descendant

Parent: `provider_free_office_reload_terminal_reconciliation_pass`

## Contract

An expired or revoked application session must produce the same bounded client
state. HTTP 401 and 403 from the fixed directory request map to
`session_unavailable`, clear in-memory authority, disable the action, remove any
partial list and show one fixed instruction to close and reopen the taskpane.
Raw GraphQL, HTTP, SQL or identity detail may not reach the UI or evidence.

## Acceptance

One revoked and one clock-expired authored-synthetic surface session must both
be denied before product data is returned. Each must admit one sanitized failed
terminal result, record no product read, and close with complete database, role
and pool cleanup.

## Limits

This changes only failure reconciliation for the existing fixed directory read.
It adds no refresh token, silent login, fallback, real identity or durable client
session behaviour.
