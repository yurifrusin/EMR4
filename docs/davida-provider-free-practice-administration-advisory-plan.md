# Davida provider-free practice-administration advisory plan

Date: 2026-08-03

Status: provider-free, unmounted, unoccupied, authored-synthetic

Parent: `provider_free_practice_administration_pure_read_pass`

## Outcome

Implement tranche 2 of the accepted Davida sequence as a pure deterministic
context-to-advisory proofreader. It consumes one already accepted
`PracticeAdministrationContextFrame`, admits exactly
`ADVISORY_EXPLAIN_DIRECTORY` or `ADVISORY_SUMMARIZE_DIRECTORY`, and atomically
releases a strict structured advisory draft whose fields are copied or derived
from that context.

This is an unoccupied proof of the boundary that would sit outside a future
Davida probabilistic work cell. There is no model/provider call, generated
prose, memory/RAG, database/network/clock access, route, GraphQL field, proposal,
confirmation, apply or write.

## Authority and scope

Yuri's standing two-lane authority covers this bounded descendant. Owned paths
are the new advisory schemas and proofreader, this plan/design/security delta,
the advisory contract/schema, a provider-free acceptance script and focused
tests. Accepted parent files, routes, `app.main`, GraphQL, models, migrations,
shared auth, manifests/API Spine, `docs/diary/**`, `docs/branding/**`, workflows,
harness settings, protected evidence and protected refs remain unchanged.

## Frozen candidate

- The operation enum contains exactly the two advisory codes. All four accepted
  parent proposal codes plus apply/confirmation/write and unknown codes fail
  before interpretation.
- Candidate models are frozen and extra-forbid. They bind the exact context
  schema, practice/principal/correlation references, content revision,
  `authority_class=advisory`, and literal-false write/proposal/confirmation
  authority.
- Explain selects exactly one `practitioner` or `location` opaque reference.
  Summary selects no target and accepts no prose, count, template, claim or fact
  value.
- `evaluated_at` is caller-supplied, canonical, timezone-aware and within the
  half-open context interval. The proofreader never reads system time.

## Frozen proofreader and release

The proofreader performs bounded canonical admission, operation allowlisting,
strict candidate validation, exact parent-context shape and SHA-256 revision
recomputation, binding/freshness checks, exact target resolution and
deterministic field derivation. It rejects coercion, stale context, count/row
drift, duplicate cross-frame references and dangling default-location
references.

A released draft is labelled `model_interpretation`, evidence mode
`provider_free_unoccupied_authored_synthetic`, status `advisory_only`, and
presentation `structured_fields_only_no_html_or_markdown`. Its grounding digest
binds the context revision, exact source paths and released payload. Its
authority ceiling sets command, confirmation, proposal, apply, write, provider,
memory, database, network, event and model-to-database fields to false.

The result is one strict discriminated `released`/`rejected` union. Both arms
carry only a canonical candidate hash, context revision and a closed reason;
repair and retry are false. Rejection contains no draft or partial payload.

## Deterministic acceptance

Acceptance covers empty/non-empty summary, practitioner explanation with and
without role/default location, location explanation, repeated byte/hash
determinism, exact contract-schema validation, recursive closed-schema checks,
all excluded operations, free-text/effectful fields, authority reversals,
scope/revision/context tampering, freshness edges, target errors, coercion,
over-bounded input and absence of forbidden imports/calls. Evidence contains
only fixed labels, counts, booleans and hashes.

Proposed result:
`provider_free_practice_administration_advisory_proofreader_pass`.

## API Spine

This is a minimal non-authoritative context transform. GraphQL remains
read-only and unused by the proofreader; REST commands, events and manifests are
unchanged. Idempotency and mutation audit fields are deliberately absent
because no external effect or state change exists.

## Residual gate

No model occupancy or mounted Davida surface is established. The next accepted
sequence item is one bounded reversible administrative proposal with a
backend-computed before/after dry run and no apply command. Any operation-vocabulary
change, real data/identity, provider, memory, command/write, deployment,
production or release is a separate gate.
