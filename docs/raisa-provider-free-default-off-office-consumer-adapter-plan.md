# Provider-free default-off Office consumer adapter plan

Date: 2026-08-03

Status: authorised fifth lifecycle descendant

Parent: `provider_free_office_lifecycle_observability_pass`

## Contract

Extract the one-use delivery, nonce admission and sanitized lifecycle decisions
into a reusable application service. The service owns no route, cookie,
database, session validation/revocation, identity or product read. Its fixed
surface/host/endpoint map is supplied by an explicitly constructed task
composition, and it remains absent from `app.main`.

## Acceptance

Tests prove one ready decision, one inert replay decision, one revocation
request returned only to the owning composition, surface-bound nonce admission,
replay and mismatch rejection, fixed sanitized reason counts, no application
mount and no provider or product side effect.

## Limits and handoff

The adapter is not product wiring. The next safe candidate is a separately
authorised composition review for a native Diary consumer of the same
least-sensitive read; broader product resources, real identity and every write
remain closed.
