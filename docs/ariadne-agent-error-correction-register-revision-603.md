This revision binds five corrected operator errors from the preset-composition
safe-terminal bridge and its closeout. The clockwork owns the canonical JSON
register and pattern report; this note supplies the prospective human-readable
reading for one atomic projection.

## AER-0874

The first focused test asserted a positive sentence that did not match the
frozen threat table's threat-labelled wording. It failed before any native
process. The assertion now binds the exact row, and future tests distinguish a
threat label from its fail-closed control rather than rewriting either in
prose.

## AER-0875

The first runner validator compared the successor identity with a predecessor
module global after that global had been temporarily rebound to the successor
value. The valid distinct-identity check therefore failed before execution.
The accepted predecessor identity is now captured once outside the rebinding
context and used as the immutable comparison value.

## AER-0876

The first preexecution receipt was generated before its own modified receipt
paths were committed. It correctly reported a dirty tracked tree and was not
used to authorise execution. The receipt was committed, then regenerated at
the committed source and recorded clean branch/origin-aligned state. Future
preexecution receipt generation occurs only after all receipt paths themselves
are committed.

## AER-0877

The first immutable-evidence test guessed a successor-specific attempt schema
name even though the generated consumed-attempt artifact intentionally retains
the inherited diagnostic schema. The focused test rejected the mismatch. The
test now binds the exact retained schema; schema identifiers are copied from
the artifact or owning schema rather than inferred from an operation name.

## AER-0878

The first inherited closeout command repeated the known incompatible use of
the provider-free test wrapper for two deterministic checks requiring the
explicit host cache-location binding. It failed with the typed
`localappdata_missing` guard and launched no native process. The command is
replaced by the predecessor-approved no-conftest pytest invocation. Closeout
command selection now carries forward recorded environment constraints instead
of reconstructing them from the test list.
